# UI artwork

Created for this project with the built-in image_gen tool on 2026-09-10. No external commercial game assets were downloaded. Both PNG files are embedded by LiarsTavern.qrc. Portrait tiles are sampled and clipped to circles at runtime; the source atlas is preserved.

## tavern-background.png — generation prompt

Use case: stylized-concept. Asset type: production background plate for an existing 1600x900 Qt card game, landscape 16:9. Create an original cinematic dark candlelit old tavern with one enormous EMPTY oval walnut gaming table seen from high angle, almost top-down. The table should occupy 92% width and 88% height: oval bounding box approximately x=4%, y=9%, width=92%, height=88%, centered horizontally. All of the table surface is uninterrupted bare wood, with fine realistic aged walnut grain and a thick rounded worn dark wooden rim with restrained bronze fasteners. Center warm amber-brown softly lit, edges fall off into deep brown shadow. Background only shows atmospheric tavern wall, barrels and candlelight around extreme margins and upper corners. Keep table center and lower half clean for UI overlay, medium-dark enough for cream text. Detailed painterly realism, premium fantasy board game art, physical material texture, warm low light, elegant composition. NO people, NO animals, NO cards, NO dice, NO mugs on table, NO UI, NO panels, NO buttons, NO labels, NO letters, NO logos, NO watermarks. Output a wide 16:9 image.

## tiger-portraits.png — generation prompt

Use case: stylized-concept. Asset type: 2 by 2 character portrait atlas for a fantasy tavern card game. A square image split into FOUR EXACT EQUAL SQUARE QUADRANTS, absolutely no gaps or margins or separators. Each quadrant contains one different original anthropomorphic tiger tavern patron, head and shoulders centered, entire head and hat visible with ample space from tile edges, looking slightly toward the camera. Top left: warm orange tiger in a moss-green felt hat and olive Victorian coat. Top right: purple-furred tiger with a dark violet top hat and elegant purple coat. Bottom left: orange tiger in a black top hat and dark charcoal formal vest. Bottom right: weathered golden tiger in a brown leather adventurer hat and brown leather coat. Each portrait has its own plain very dark warm brown background. Detailed painterly realism, amber candle rim light, expressive clever faces, premium illustrated card game art. No lettering, no frames, no medallions, no logos, no watermark, no UI, no weapons. Portraits are designed to be cropped into circles later by the game; keep the faces and hats within the centered 85% diameter of each square tile. Four distinct portraits exactly one per quadrant.
